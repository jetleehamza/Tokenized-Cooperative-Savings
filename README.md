# Tokenized Cooperative Savings
A decentralized cooperative savings platform built on Stacks blockchain where members can contribute funds and collectively decide on investments through voting.

## 🌟 Features

- Member registration system
- STX token contributions
- Democratic proposal creation and voting
- Secure fund management
- Automated proposal execution

## 🔒 Security Features

- Access control checks for members
- Input validation for contributions and withdrawals
- Deadline-based proposal execution
- Vote duplication prevention
- Balance verification

## 🚀 Getting Started

### Prerequisites

- Clarinet
- Stacks wallet
- Node.js

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/tokenized-cooperative-savings
```

2. Install dependencies
```bash
cd tokenized-cooperative-savings && clarinet install
```

3. Run tests
```bash
clarinet test
```

## 💻 UI Features

The dApp includes:
- Dashboard showing total savings and member count
- Proposal creation form with amount and description
- Voting interface with remaining time display
- Member contribution history
- Active proposal list with vote counts
